# Coursework provenance

Author: Justin Spratt

This project draws on Justin Spratt's CSS321 Software Assurance Guidelines Document IP5 and revised Individual Project 4, dated February 5, 2026. Appendix B provided a Java order lookup with format validation and a JDBC prepared statement. The coursework also discussed access control, audit evidence, and CI security gates.

The repository expands that example with a relational schema, products and order items, spending reports, fictional seed data, agency-scoped authorization, buyer/viewer roles, transactional audit writes, executable tests, and a local demonstration. These additions are portfolio implementation work; they were not all present in the submitted coursework.

The original organizational case study has been adapted to fictional public-sector purchasing. There is no claim of affiliation with, employment by, or deployment at the organization discussed in the assignment. Source coursework files have not been modified or copied into this repository. No classmates' documents or code were used.

Only Justin Spratt is listed as project author. External libraries and technical references retain their own attribution and terms.
